Неверный логин или пароль.
Демо: обычный пользователь — user / user123; администратор — admin / admin123.

Новая функция: Администратор может изменять email и отображаемое имя любого пользователя. Изменения сохраняются в localStorage / экспорт HTML.

Сохранение на GitHub (GitHub Pages)

Страница сделает коммит обновлённого `5.html` через GitHub API.

Важно: токен даёт доступ к вашему GitHub. Создайте Fine-grained token с доступом только к одному репо и правом Contents: Read/Write. Мы сохраним токен в localStorage этого браузера.
Не используйте токен с доступом ко всем репозиториям.
Заполните поля и нажмите «Сохранить».
